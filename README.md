# student-style-solution

将 AI 生成的讲解式解答转换为可直接誊写的演算稿，适用于 Claude Code 等 agent。

> 本技能为个人自用，尚未完善，规则会随使用情况继续调整。

## 背景

大学课堂上，教师随堂发一道题，要求当场完成并提交。题目涉及的章节此前没学过，学生无法独立推导，只能交给 AI 求解。

AI 返回一份完整讲解：先交代理想化假设，再复述公式来历，列出两三种等价写法，末尾附代回检验和加粗的「综上」结论。作为讲解没有问题，作为答卷则与题目要求不匹配：

- 篇幅与分值不相称，相当一部分内容不构成得分点；
- 必要的推导和可有可无的说明混在一起，分辨不出哪几行必须保留；
- 内容超出当前进度，读不懂也就无法核对，只能整段照抄；
- 全部照抄会写满一页半，自行删减又容易删掉关键步骤。

最后交上去的往往既不是 AI 的原稿，也不是自己的思路，而是一份中途删改过的版本。

`student-style-solution` 不追求更详细的解答，只把解答压缩到与题目相称的程度。

## 技能做什么

数学、物理、化学和工科题目均可使用。输出是一份演算稿，只包含可按顺序落笔的步骤：

- 按 `(1)`、`(2)` 分问，第一行即 `(1)`，不写「解：」「答案：」「综上」；
- 一条结论一行，以 `公式 = 代入 = 结果` 串联，行末带单位；
- 公式用纯文本：`2π/T`、`√(R³/GM)`、`ω²`，不写 LaTeX；
- 文字只保留 `∵`、`∴`、`⇒` 和「势能：」这类六字以内的提示；
- `π²`、`√2` 不展开为小数，有效位数跟随题干。

判断标准只有一条：

> 原样抄到答题纸上，不需要删任何一句，也不需要补任何一步。

## 输出示例

数值计算题：

```text
(1)

T = 32/48 = 2/3 s

ω = 2π/T = 3π rad/s

k = mω² = 0.1 × (3π)² = 0.9π² N/m

F = kA = 0.9π² × 0.05 m = 0.045π² N

(2)

系统总能量：

E = ½kA² = ½ × 0.9π² × 0.05² = 1.125×10⁻³π² J

势能：

E_p = ½kx² = ½ × 0.9π² × 0.01² = 4.5×10⁻⁵π² J

动能：

E_k = E − E_p = 1.08×10⁻³π² J
```

## 不输出的内容

- **过渡语**：`可得`、`故`、`即`、`注意`、`检验`、`验算`、`另解`、`等价`、`综上`、`因此`、`所以`，其中「所以」统一改为 `∴`；
- **等价形式与验算**：一种写法即可，不附「代回检验」，不给第二种形式；
- **近似值**：答案行不出现 `≈`，`π²`、`√2` 保留到答案；近似值也不进入后续算式，`cos φ = 7.5/10.6` 应写作 `√2/2`；
- **自造符号**：不引入辅助角 `β`，不新设 `t_AB`、`t_B→max` 一类下标；
- **无依据的跳步**：教材公式可以省去推导，但建模依据（势能零点的选取、相位的正负判断等）必须保留一行 `∵` 或 `∴`。

## 适用范围

本技能面向「要交的答案」，不面向「要讲的道理」。

- 适用：作业、随堂测、考试练习等需要写出完整过程的场合；
- 不适用：要求讲解思路、解释某一步的依据、点评解答对错、比较多种解法。

判断依据是目的：为了理解，就用讲解；为了交卷，就用本技能。拿到演算稿后继续追问原理时，切回讲解，不再套用本格式。

## 安装与使用

将 `student-style-solution/` 目录放入技能目录（个人级 `~/.claude/skills/`，或项目级 `.claude/skills/`），新开会话后直接粘贴题目即可，无需附加说明。

## 规则的来源

本技能的规则来自一组本地题目对照实验：每道题分别记录原题、按本技能生成的解答、学生实际写出的解答，以及两者的差异分析。通用写法从对照结论中提炼，再回写至 `SKILL.md`。对照记录不随仓库发布。

## 关于「学生体」

「学生体」指按学生答卷的习惯写：只写公式、代入与判断，不写讲解。这种写法并不省略思考，只是把两件事分开：理解发生在动笔之前，交付是一次干净的誊写。

讲义留给课堂，演算稿留给答题纸。
